## 1. Raw Data Schemas

### 1.1 Order Book Snapshots

**File**: `data/raw/order_book_snapshots.parquet`
**Generated by**: `python/data_generation/synthetic_generator.py`
**Frequency**: Every `snapshot_interval_ms` milliseconds (default: 100ms)

| # | Column | Type | Nullable | Description |
|---|--------|------|----------|-------------|
| 1 | `timestamp` | `datetime64[ns]` | No | Snapshot timestamp in IST (nanosecond precision) |
| 2 | `symbol` | `string` | No | Instrument identifier (e.g., `RELIANCE`, `NIFTY_FUT`) |
| 3 | `bid_price_1` | `float64` | No | Best bid price (Level 1) |
| 4 | `bid_price_2` | `float64` | No | Second-best bid price (Level 2) |
| 5 | `bid_price_3` | `float64` | No | Third-best bid price (Level 3) |
| 6 | `bid_price_4` | `float64` | No | Fourth-best bid price (Level 4) |
| 7 | `bid_price_5` | `float64` | No | Fifth-best bid price (Level 5) |
| 8 | `bid_size_1` | `int64` | No | Quantity at best bid (Level 1) |
| 9 | `bid_size_2` | `int64` | No | Quantity at Level 2 bid |
| 10 | `bid_size_3` | `int64` | No | Quantity at Level 3 bid |
| 11 | `bid_size_4` | `int64` | No | Quantity at Level 4 bid |
| 12 | `bid_size_5` | `int64` | No | Quantity at Level 5 bid |
| 13 | `ask_price_1` | `float64` | No | Best ask price (Level 1) |
| 14 | `ask_price_2` | `float64` | No | Second-best ask price (Level 2) |
| 15 | `ask_price_3` | `float64` | No | Third-best ask price (Level 3) |
| 16 | `ask_price_4` | `float64` | No | Fourth-best ask price (Level 4) |
| 17 | `ask_price_5` | `float64` | No | Fifth-best ask price (Level 5) |
| 18 | `ask_size_1` | `int64` | No | Quantity at best ask (Level 1) |
| 19 | `ask_size_2` | `int64` | No | Quantity at Level 2 ask |
| 20 | `ask_size_3` | `int64` | No | Quantity at Level 3 ask |
| 21 | `ask_size_4` | `int64` | No | Quantity at Level 4 ask |
| 22 | `ask_size_5` | `int64` | No | Quantity at Level 5 ask |
| 23 | `bid_orders_1` | `int32` | No | Number of resting orders at best bid |
| 24 | `bid_orders_2` | `int32` | No | Number of resting orders at Level 2 bid |
| 25 | `bid_orders_3` | `int32` | No | Number of resting orders at Level 3 bid |
| 26 | `bid_orders_4` | `int32` | No | Number of resting orders at Level 4 bid |
| 27 | `bid_orders_5` | `int32` | No | Number of resting orders at Level 5 bid |
| 28 | `ask_orders_1` | `int32` | No | Number of resting orders at best ask |
| 29 | `ask_orders_2` | `int32` | No | Number of resting orders at Level 2 ask |
| 30 | `ask_orders_3` | `int32` | No | Number of resting orders at Level 3 ask |
| 31 | `ask_orders_4` | `int32` | No | Number of resting orders at Level 4 ask |
| 32 | `ask_orders_5` | `int32` | No | Number of resting orders at Level 5 ask |
| 33 | `mid_price` | `float64` | No | Midpoint: `(bid_price_1 + ask_price_1) / 2` |
| 34 | `spread` | `float64` | No | Quoted spread: `ask_price_1 - bid_price_1` |
| 35 | `microprice` | `float64` | No | Size-weighted mid: `(bid_price_1 × ask_size_1 + ask_price_1 × bid_size_1) / (bid_size_1 + ask_size_1)` |

**Primary Key**: (`timestamp`, `symbol`)

### 1.2 Trade Prints

**File**: `data/raw/trade_prints.parquet`
**Generated by**: `python/data_generation/synthetic_generator.py`

| # | Column | Type | Nullable | Description |
|---|--------|------|----------|-------------|
| 1 | `timestamp` | `datetime64[ns]` | No | Trade execution timestamp (nanosecond precision) |
| 2 | `symbol` | `string` | No | Instrument identifier |
| 3 | `price` | `float64` | No | Trade execution price |
| 4 | `size` | `int64` | No | Trade quantity (number of shares/lots) |
| 5 | `side` | `string` | No | Aggressor side: `BUY` (buyer-initiated) or `SELL` (seller-initiated) |
| 6 | `trade_id` | `int64` | No | Unique trade identifier (sequential) |
| 7 | `order_id` | `int64` | Yes | Originating order ID (if available) |

**Primary Key**: (`trade_id`)

### 1.3 Order Events

**File**: `data/raw/order_events.parquet`
**Generated by**: `python/data_generation/synthetic_generator.py`

| # | Column | Type | Nullable | Description |
|---|--------|------|----------|-------------|
| 1 | `timestamp` | `datetime64[ns]` | No | Event timestamp (nanosecond precision) |
| 2 | `symbol` | `string` | No | Instrument identifier |
| 3 | `event_type` | `string` | No | Event type: `NEW`, `MODIFY`, `CANCEL`, `FILL` |
| 4 | `order_id` | `int64` | No | Unique order identifier |
| 5 | `side` | `string` | No | Order side: `BID` or `ASK` |
| 6 | `price` | `float64` | No | Order price |
| 7 | `size` | `int64` | No | Original order quantity |
| 8 | `remaining_size` | `int64` | No | Remaining quantity after this event |
| 9 | `queue_position` | `int32` | Yes | Position in price-level queue (1-indexed) |

**Primary Key**: (`timestamp`, `order_id`, `event_type`)

**Event Type Definitions**:

| Event Type | Description |
|------------|-------------|
| `NEW` | New limit order submission. `remaining_size` = `size` |
| `MODIFY` | Price or size modification. `remaining_size` reflects updated quantity |
| `CANCEL` | Order cancellation. `remaining_size` = 0 |
| `FILL` | Partial or complete fill. `remaining_size` = quantity remaining after fill |

### 2.7 Hawkes Parameters

**File**: `data/processed/hawkes_params.csv`
**Generated by**: `R/07_hawkes_intensity.R`

| # | Column | Type | Description |
|---|--------|------|-------------|
| 1 | `symbol` | `string` | Instrument identifier |
| 2 | `event_type` | `string` | `trade`, `submission`, `cancellation`, `modification` |
| 3 | `mu` | `float64` | Estimated baseline intensity (events/sec) |
| 4 | `alpha` | `float64` | Estimated excitation magnitude |
| 5 | `omega` | `float64` | Estimated decay rate |
| 6 | `branching_ratio` | `float64` | `alpha / omega` (must be < 1) |
| 7 | `half_life_ms` | `float64` | `ln(2) / omega × 1000` |
| 8 | `unconditional_intensity` | `float64` | `mu / (1 - branching_ratio)` |
| 9 | `log_likelihood` | `float64` | Log-likelihood at MLE estimate |
| 10 | `aic` | `float64` | Akaike Information Criterion |
| 11 | `num_events` | `int64` | Number of events in estimation window |

### 2.8 Correlation Matrix

**File**: `data/processed/correlation_matrix.csv`
**Generated by**: `R/08_cross_metric_correlation.R`

A square matrix of pairwise Pearson correlations between all computed metrics. Rows and columns are metric names.
